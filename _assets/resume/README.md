# Résumé generator

`public/Akhmad_Kholmurodov_Resume.pdf` is generated by `build-resume.mjs`, not
hand-edited. Editing the PDF directly means the next change starts from
scratch; editing the script means it stays a one-line diff.

## Regenerating

```sh
npm i pdfkit                      # not a dependency of the site — install anywhere
node build-resume.mjs ../../public/Akhmad_Kholmurodov_Resume.pdf ../../public/akhmad.jpeg
```

It prints how much of the page the content fills:

```
  sahifa: 770 / 782 pt  (bo'sh 12pt)
```

**It must stay on one page.** If that line reports `TOSHDI`, cut wording rather
than shrinking type — the body is already at 8.45 pt, which is the floor for
something a hiring manager reads on paper.

## Editing

All copy lives in the `C` object at the top. Layout constants are in `S` and
`M` below it. The `Lato` font files come from the system
(`/usr/share/fonts/truetype/lato/`); on a machine without them, point `FONT` at
any other TTF family.

## Why it looks the way it does

- **One page.** Three years of experience does not justify two, and the résumé's
  job is to earn a click through to the portfolio, not to replace it.
- **Photo top-right.** Standard for Korean hiring; cropped to 3:4 and boxed so it
  reads as a document photo.
- **Visa and Korean level in the header.** They are the first things a Korean
  screener checks, and burying them costs interviews.
- **Real text, single column.** Survives an ATS parse; the accent colour is dark
  enough (`#00706b`) to stay legible in greyscale print.
